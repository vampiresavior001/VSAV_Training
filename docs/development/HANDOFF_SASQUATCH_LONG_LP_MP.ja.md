# Claudeへの引き継ぎ：サスカッチのロングダッシュLP→MP

対象リポジトリ：vampiresavior001/VSAV_Training
対象ブランチ：fc2-v11

## 目的と確定した方針

既存のShort LP（ショートダッシュ小P）と対になる、サスカッチのロングダッシュLP→MPを教材として用意してください。

- Action Stepsは、動作とタイミングを指定して一連の動きを定義する機能です。
- Action Patternsは、作ったStepsを名前付きで複数保存・管理し、候補からランダムに実行する機能です。
- 教材は「Short LPを単独で練習→ロング版を単独で確認→両方を選んでランダム実行」の順にします。
- 単にShort LPのタイミングをずらす教材ではありません。既存のRandom Delayの応用は残してください。

ロング版の具体的なWait、方向、LP→MPのつなぎ方は未確定です。名称だけから推測して完成扱いにしないでください。

## 1. 動作とデータを用意する

1. 最新のブランチと既存の `scripts/patterns/Sasquatch_Short_LP.json` を確認してください。
2. サスカッチのロングダッシュからLP→MPが出るAction Stepsを作ってください。ショートダッシュ用のForward Cancelを流用する前提にはせず、ロングダッシュとして意図した動きを確認してください。
3. 各ステップのAction、Direction／Button、Wait、Random Delay、必要ならHoldを記録してください。最初は追加のランダム待ちを0にして再現性を確認します。
4. ガードをきっかけに単独で実行し、意図したLP→MPが出ることを確認してください。ゲーム速度、相手キャラクター、開始間合い、左右配置、成立する条件も記録してください。
5. Action Patternsに保存し、`Export this Pattern`で書き出してください。仮の表示名は `Long LP MP`、ファイル名は `Sasquatch_Long_LP_MP.json` とします。既存の命名慣習に合わなければ調整して構いません。
6. 書き出したファイルを取り込み直し、同じ動きになることを確認してください。
7. Short LPとロング版だけを使用候補にして、両方が選ばれることを確認してください。Loopを教材に含める場合は、両方の動きと周回間の遷移が成立することを別途確認してください。

エミュレーターを操作できない場合は、データと設定案を未検証と明記し、ユーザーに必要な操作確認を依頼してください。未確認のTick値や成功結果を補わないでください。

必要な画像は次の2枚です。画像生成や合成で設定画面・結果を作らず、確認した環境のスクリーンショットを使ってください。

|---|---|---|

## 3. 日英マニュアルへ組み込む

素材と動作確認がそろってから、既存のサスカッチ・チュートリアルの応用として追加してください。

1. 最初のShort LPによるAG・GC練習は短いまま維持する。
2. ロング版を取り込み、それだけを[x]にして動作を確認する。
3. Short LPとロング版の両方を[x]にし、反撃の機会ごとに異なる一連の動きが選ばれることを説明する。
4. 同じ動きを固定で練習する段階から、異なる攻めに対応する練習へ進むことを説明する。
5. Short LPだけに戻す操作も記載する。

「2種類を交互に実行する」「必ず同じ間合いに戻る」「両方とも同じ入力でAG・GCできる」とは、確認なしに書かないでください。ランダム選択では同じ候補が続く場合があります。

日本語はAG・記録、英語はPB・recordingとし、英語は米国式表記にそろえてください。共有・取り込みはPatternsの補助機能として説明し、複数管理とランダム実行を中心にしてください。
